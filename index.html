채팅 로그 백업기

캐릭터와 대사를 입력하면 말풍선 미리보기와 HTML 코드를 생성합니다.

1. 캐릭터 설정

A는 왼쪽, B는 오른쪽, C와 그 이후 캐릭터는 모두 왼쪽에 표시됩니다.

2. 대사 입력

캐릭터 이름은 설정에 입력한 이름과 일치해야 합니다. 같은 이름을 여러 번 사용해도 됩니다.

입력 내용은 이 브라우저의 저장 공간에도 자동 저장됩니다. 다른 기기와 동기화되지는 않으므로 JSON 백업 파일을 별도로 보관하세요.

3. 미리보기

캐릭터와 대사를 입력하면 여기에 표시됩니다.

4. 생성된 HTML

블로그의 HTML 편집 모드 등에 붙여 넣을 수 있습니다.
